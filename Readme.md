# 壁紙メーカー

写真フォルダから画像を読み込み、コルクボードに写真を押しピンで留めたような壁紙画像を自動生成するデスクトップアプリです。

CustomTkinter でダークモード風の画面を作り、Pillow で画像の合成・回転・保存を行います。

## 主な機能

- 写真フォルダの選択
- 写真フォルダやコルク背景画像のドラッグ＆ドロップ
- JPG / JPEG / PNG / HEIC / HEIF 画像の読み込み
- シームレスなコルク画像を背景として読み込み、壁紙全体にタイル表示
- 1920x1080、2560x1440、3840x2160 の壁紙解像度に対応
- コルク背景画像を指定しない場合は、自動生成のコルク風テクスチャを使用
- 写真のランダム配置と回転（角度はスライダーで調整）
- 右側パネルのスライダーで枚数・回転・余白・カードサイズ・位置のゆらぎを調整
- グリッド、タイムライン帯状、放射状、主役写真＋周囲写真の4レイアウトを選択
- 「既定値に戻す」でスライダーを初期値にリセット
- グリッドのセルへ写真を1枚ずつ割り当て、重なりを抑えた配置
- 写真枚数と壁紙の縦横比に応じてグリッドを自動調整
- 「再生成」ボタンによる配置のシャッフル
- 上左からのやわらかな光と、周辺を少し落としたコルク背景の陰影
- 紙の縁のハイライトと、下右へ落ちるドロップシャドウを備えたポラロイド風フレーム
- 赤、黄色、青の押しピン風グラフィック
- 生成結果のプレビュー
- JPG または PNG 形式で保存

## 必要な環境

- Windows / macOS / Linux
- Python 3
- CustomTkinter
- Pillow
- pillow-heif

Tkinter は CustomTkinter が内部で利用する Python の標準ライブラリです。環境によっては別途 Tkinter の導入が必要です。

## インストール

プロジェクトフォルダで、プロジェクト専用の仮想環境を作成して依存パッケージをインストールしてください。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install customtkinter Pillow pillow-heif
.\.venv\Scripts\python.exe -m pip install tkinterdnd2
```

PowerShell で仮想環境を有効化してからインストールする場合は、次のように実行できます。

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\.venv\Scripts\Activate.ps1
python -m pip install customtkinter Pillow pillow-heif
python -m pip install tkinterdnd2
```

## 起動方法

プロジェクトフォルダで、`.venv` の Python を指定して起動します。

```powershell
.\.venv\Scripts\python.exe app.py
```

または、仮想環境を有効化してから起動します。

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\.venv\Scripts\Activate.ps1
python app.py
```

## 使い方

1. 「フォルダを選択」をクリックします。
2. JPG、JPEG、PNG、HEIC、または HEIF 写真が入ったフォルダを選択します。
3. 必要に応じて「コルク背景を選択」をクリックし、背景に使うコルク画像を選択します。
4. 「壁紙解像度」から出力サイズを選択します。
5. 右側の「配置の調整」でレイアウトとスライダーを選び、見た目を調整します（任意）。
6. 「生成」をクリックしてプレビューを作成します。
7. 配置を変えたい場合はスライダーを動かしてから「再生成」をクリックします。
8. 「壁紙を保存」をクリックし、保存先とファイル形式を選択します。

フォルダをウィンドウ上部の「フォルダまたは背景画像をここへドロップ」へドロップすると、写真フォルダとして設定できます。JPG、JPEG、PNG、HEIC、または HEIF の画像をドロップすると、コルク背景画像として設定できます。

写真はフォルダ内からランダムに選ばれ、グリッド状のセルへ1枚ずつ配置されます。使用枚数はスライダー「写真枚数」で指定し、フォルダ内の枚数を超える場合は存在する枚数までに制限されます。セル内の位置と角度は生成ごとに変わります。

### 配置スライダーについて

| 項目 | 範囲 | 説明 |
|------|------|------|
| 写真枚数 | 4〜20 枚 | 壁紙に使う写真の枚数（フォルダ内の枚数が上限） |
| 回転の最大角度 | 0〜30° | 各カードの傾きの最大値（0 でほぼ水平） |
| 余白 | 10〜120 px | 画面端からの余白（1920 幅基準。解像度に応じて拡大縮小） |
| カードサイズ | 50〜95 % | 各グリッドセルに対するカードの大きさ |
| 位置のゆらぎ | 0〜80 % | セル中心からのずれ量（0 で整列寄り） |

### レイアウトについて

| レイアウト | 説明 |
|------|------|
| グリッド | 写真を画面全体へ均等に配置します。 |
| タイムライン | 写真を横方向の帯に沿って交互に配置します。 |
| 放射状 | 写真を中央から円形に広がるよう配置します。 |
| 主役＋周囲 | 1枚を中央に大きく置き、残りを周囲に小さく配置します。 |

### コルク背景画像について

「コルク背景を選択」で JPG / JPEG / PNG / HEIC / HEIF 画像を指定できます。画像は壁紙全体を埋めるように横方向・縦方向へ繰り返し配置されます。継ぎ目を目立たせないため、上下左右が自然につながるシームレステクスチャを使用してください。

背景画像を選択しない場合は、アプリ内で生成したコルク風テクスチャが使われます。

## トラブルシューティング

### `No module named 'PIL'` と表示される

必要なPythonパッケージがインストールされていません。次のコマンドを実行してください。

```powershell
.\.venv\Scripts\python.exe -m pip install customtkinter Pillow pillow-heif
```

複数の Python をインストールしている場合は、アプリ起動に使用する Python と同じ実行ファイルで Pillow をインストールしてください。

### 写真が見つからないと表示される

選択したフォルダに、拡張子が `.jpg`、`.jpeg`、`.png`、`.heic`、または `.heif` の画像を入れてください。

### 生成に時間がかかる

4K（3840x2160）を選択した場合や、写真の枚数が多い場合は、フルサイズ画像の合成に時間がかかることがあります。生成中は画面下部のステータス表示を確認してください。

## 注意事項

- 同じフォルダから生成しても、写真の配置や回転は毎回変わります。
- 出力画像は壁紙用のRGB画像として保存されます。
- 元の写真ファイルは変更されません。
